# Security policy

## Supported versions

Only the latest release of `@gjermundgaraba/effect-actions` receives fixes. Releases may break
the API without a compatibility period, so a fix ships in a new release rather than as a backport.

## Reporting a vulnerability

Report it privately through GitHub:
[Report a vulnerability](https://github.com/gjermundgaraba/effect-actions/security/advisories/new).
Do not open a public issue.

Include the affected version, the surface involved (HTTP, MCP, Toolkit, CLI), and a reproduction.
