# Approval

`needsApproval` is one function over every call, `(call, context) =>`, whose `call` is a union by action name, so checking `call.name` narrows `call.input`. This reverses the per-action option, a function of each action run once by `make` (0a99a00) returning its tool's native approval (0db3f3a), whose input was the union of every action's, so `action.name === "erase" ? ({ hard }) => hard : false` did not compile. Rejected: a record keyed by action name, which takes an entry per action for a rule over every action, such as `!call.action.readOnly`. It returns the native `boolean | Effect<boolean>`, requiring nothing: `LanguageModel` runs it in the caller's context, so it reads the caller with `Effect.serviceOption`, and a policy per caller needs no toolkit per caller. Its error channel is `never`: `LanguageModel` reads a failed rule as no approval needed, so a rule decides what its failure means rather than failing open unseen.
