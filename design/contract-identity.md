# Contract identity

A contract states who may call it, `caller: Action.Anyone` or the identity service a caller must have, required on every `Action.make`, and every surface enforces it whatever the handler reads: a remote surface authenticates through the descriptor its binding or endpoint names, before decoding, and a local one owes the identity per call and fails a call without it with `Unauthenticated`. `{ authorize }` is required exactly where an implementation holds a protected action, and refused where it holds none, since nothing would run it; `Action.allowAll` means every authenticated caller. This reverses the earlier required hook (since 09051f7), where every `implement` stated a hook and authentication was router middleware the host provided around layers: a protected action given to a public layer answered anyone, and an admin write whose handler read no identity compiled with no authentication around it. One identity per action and per remote surface; tenants and other context stay ordinary request services. Identity declarations are `Context.Service`s, so contracts importing them stay browser-safe, which no type checks for an application's own modules. Rejected: `caller` naming the authentication descriptor, `caller: Login`, which would drop the `authentication` options of bindings and endpoints, but put `HttpApiSecurity` on every contract, which never imports transport code, for every Toolkit-only or CLI-only consumer.
