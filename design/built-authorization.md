# Built authorization

An authorizer may be built by an Effect, as handlers are, and each implementation keeps it in a memoized layer of its own beside its handlers'. `Effect.isEffect` tells the two forms apart, as it tells a builder from a handler, so an `Effect.fn` authorizer stays plain, and a service whose value is the authorizer builds it once per layer graph for every implementation it guards. A built authorizer's own state is per implementation; state shared across implementations belongs in a service. The type keeps the builder's failures and services apart from the handlers' (`~authorizeBuildError`, `~authorizeBuildServices`). Lost: `Action.share` is removed, so another authorizer over the same handlers takes another `implement` of the same builder Effect, whose builder then runs once per implementation in each layer graph.
