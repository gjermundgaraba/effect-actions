# Stdin field

A derived command reads one field from standard input when its options name it, `stdin`, instead of from a flag: a secret given as a flag stays in the process list and the shell's history, so a CLI storing one had to write that command by hand with native `Command.make`, and it then checked the input, printed failures and validated output its own way, beside derived commands that print the JSON HTTP sends. The field may be of any kind: a string's, a template literal's or a choice's text is its value as it is, and any other field's is JSON the field accepts, or else the text, as a value flag reads it, an array and a boolean included, whose flags repeat and switch instead. So the action's schema decodes it, and an empty value or a malformed date is the contract's to refuse, as `InvalidInput`. The field must be required, which the types and a check when the command is built both hold to: an empty stdin read for an optional field would have to mean either an empty value or the field left out. The text is all of stdin, until it closes, without the line endings that end it, as a shell's command substitution drops them, since `echo` and `op read` add one; line endings inside it stay. A terminal is refused as `InvalidInput` naming the field rather than read, since what is typed there is shown. `Stdio` is part of the environment `Command.run` requires of its host, so the command reads it with `Effect.serviceOption` without requiring it in its type, and a command without `stdin` requires nothing more than before; the cost is a branch for a missing `Stdio` that no run reaches. Help lists flags and arguments alone, so the command's description gains a sentence naming the field and its description. Lost: an optional field from stdin; more than one field; the whole input of a command taking `--input`; and typing a value at a hidden prompt. Rejected: a flag taking `-` for stdin, which still shows a flag that must never be given a value; a hidden prompt on a terminal, which needs raw terminal input and still cannot be scripted; the field limited to strings, which repeats the flag's conversion in a type, a check and an error, and whose type reads the schema's own encoding where flags read the JSON one, so a `Schema.Date` field would be refused by one and taken by the other; and leaving such commands to the host, which is how each host came to fail and print differently.
