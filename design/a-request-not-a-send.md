# A request, not a send

`Testing.mcpRequest` returns the native `HttpClientRequest`, and the test sends it: `HttpClient.execute` under `layer`, or `HttpClientRequest.toWebResult` for a web handler or `fetch`. Rejected: returning an Effect of the response, as 0.10.0's migration mapped 0.9.0's `Request`: five downstream projects' Promise tests assert on a web `Response`, and each wrote an adapter to get one back. Its default `url` is the relative `/mcp`, as `mcpClient`'s. Rejected: an absolute `http://localhost/mcp`, since an `HttpClient` with a base URL of its own, such as a test server's, applies it only to a relative URL, and every Promise caller passes its own origin anyway. Not restored: `mcpCall`, as an untyped call is this request with the result read from the response's JSON, and `withMcpClient`, whose peer dependency went with it.
