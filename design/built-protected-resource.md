# Built protected resource

`Authentication.layer`'s `protectedResource` is a plain resource or an Effect that builds one, told apart by `Effect.isEffect`, as a built authorizer is, run once per layer graph where the middleware's layer is built, its failures, services and scope the layer's, and may succeed with none. A downstream SDK learns its resource from a service at startup, and wrapping the authentication in `Layer.unwrap` left a plain `Layer` its consumers could no longer `.combine` with middleware of their own. A plain resource is checked where `layer` is called, so a misconfigured literal throws at module load; a built one when the layer builds, the check a defect there, never per request. Rejected: the Effect building the verifier returning the resource beside it, which every caller would write for the one that builds its resource. Only a request whose URL may resolve to a discovery path is parsed; every other request skips it. The URL parser copies `.well-known` as it is, removing only a tab or a newline, which Node refuses in a target before routing, while a platform passing one through still parses it.
