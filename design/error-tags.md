# Error tags

`Action.make` and `ActionHttp.make` refuse only an error with a built-in error's `_tag`: every surface declares the built-in ones, a client would decode a look-alike as one, and a look-alike of a refusal would step up, as `recordStepUp` recognizes a refusal by its schema. Rejected: distinct tags among the errors one caller may receive, which refused a form, not an ambiguity: the same schemas were accepted as members of one union, which `HttpApi` receives alike. Errors sharing a `_tag` are told apart by their other fields, the first schema that decodes winning, as in any union; whether two overlap is their author's design. Effect suffixes a repeated identifier in a JSON Schema document, so OpenAPI stays valid. A top-level `Schema.suspend` in `error` is resolved for the check, so one whose thunk reads a later `const` still throws at `make`. The built-in classes are nominal, a private type-only member each: an error of the same `_tag` and fields, Effect's `HttpApiError.Forbidden` or the application's own, compiled as one and then failed to encode, since a class's codec encodes only its instances, a defect in process and an empty 500 over HTTP. This corrects 0.10.0's notes, which said such an error was sent as the built-in. Cost: two installed copies of the package no longer accept each other's built-in errors in the types, as their codecs never accepted them at run time.
