# Successes unwrapped

A success is sent as it is, never wrapped. 2026-07-28 carries any encoded success as `structuredContent`, a bare number, string, array or `null` included, with its JSON as text, and Claude Code accepts all of them. On the earlier revisions Effect's adapters decide, not our code: 2025-11-25 and 2025-06-18 structure, and list an `outputSchema` for, only an object; a success they do not structure is text alone, a string as itself. This reverses the earlier decision to keep the `{ value }` envelope while stdio serves the 2025 revisions: 0.8.0 already shipped bare successes, and a downstream app documents them, so the envelope would wrap them again now and unwrap them again when those revisions go. The Python SDK rejects a `null` `structuredContent` (python-sdk#3345); that is the SDK's bug.
