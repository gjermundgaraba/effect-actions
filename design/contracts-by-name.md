# Contracts by name

`Action.byName(actions)` keys a list by action name, each entry its exact contract. This partly restores 0.9.0's `ActionGroup.contracts`, keyed by the action's name alone where it keyed by group and action. Rejected: 0.10.0's migration to the list itself, since a list serves a surface, not a helper that takes a name: three downstream projects rebuilt the record, one with `Extract` aliases, which do not resolve under a generic name. It types the list by its members, as every surface does, so a list narrowed at runtime is typed as holding what it may not, and `byName` then has no entry. Rejected: refusing such a list in the types, as each attempt left a shape that defeated it: keying a list of unknown length by `string` held only under `noUncheckedIndexedAccess`, and requiring a tuple of actions each of one name still passed a variadic tuple and a union of tuples. The guarantee is stated once, in the guarantees, not proven in a signature.
