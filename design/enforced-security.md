# Enforced security

OpenAPI security follows each contract's `caller`: `ActionHttp.make` gives every protected endpoint the native security middleware of the binding's authentication descriptor, and `layer` satisfies it with the descriptor's provider, so the middleware that documents security, and survives `addHttpApi`, Swagger and Scalar, is the one that authenticates. A public endpoint states `security: []`. Rejected: `security` and `public` options on `make`, documenting the authentication around the routes: they stated one split twice and could drift, and a route documented as protected was open in a layer without authentication. Effect has no OAuth or OpenID Connect scheme, so an OAuth resource is documented as a bearer. Serving `Http.api` with the native `HttpApiBuilder` fails on the missing middleware.

A descriptor names one native scheme, Bearer by default, and its verifier receives the credential Effect's decoder for that scheme gives, so the header is read once. This reverses the Bearer-only rule, under which `make` threw for Basic, an API key or a cookie: a browser app with a session cookie, which 0.8.0's middleware served, lost its protected actions, and the per-scheme verifier record and fallback it fed were dead code. Rejected: several schemes per descriptor, a per-request ambiguity no consumer has asked for. OAuth stays Bearer's: only a Bearer descriptor takes a `protectedResource` and steps a refusal up, so no other scheme sends an `insufficient_scope` challenge its clients would not act on. Another scheme's 401 carries the challenge it has: an `Http` scheme names itself, Basic names its realm, the descriptor's name, and an API key none. Basic counts a credential presented when its user-id or its password is non-empty, as a token is commonly sent as the password with an empty user-id.

A descriptor's name is an OpenAPI component key, `[A-Za-z0-9_.-]+`, which `make` throws for otherwise, and keys its scheme as it is. Rejected: a key per scheme kind, which made two API-key descriptors in one document conflict; and replacing every other character with `_`, which gave distinct names such as `app/Login` and `app:Login` one key, which Effect's `OpenApi.fromApi` merges silently where their schemes are equal. Lost: `example/Login` is written `example.Login`.

Over HTTP, a library middleware between the layer's middleware and the authentication answers a step-up refusal as it leaves the layer's middleware, so one recovering from it keeps its own response, and one turning it into another declared error answers with that error; recorded in the handler, the refusal overrode both, and the native security middleware sees a route's failure only wrapped in a private type. Over MCP a tool's failure is a successful result, so a recorded refusal answers however the request ended. Only protected actions record one: a public action's refusal is its result, signed in or not.
