# ActionDurableObject failure modes

Messages the library does not own, workerd's, celld's, the compiler's and Effect's, and the fix. Search for a fragment of the message; one the library throws says its own fix. The tasks are in [ActionDurableObject.md](ActionDurableObject.md); a surface's own failures are in the core's `*-failures.md` pages.

- `is not assignable to type 'Allowed<never, never>'` at `make`'s or `handlers`' `routes`, or `Allowed<X, Y>` where the routes provide `X` and `services` provides `Y`: the routes require a service no Layer provides; those in the union other than `State`, `Sockets`, `HttpRouter`, the platform's and `Y` are missing, so add their Layers to `services` or provide them to the routes, and a `Request<"Requires", Z>` is read per request, as the core's `ActionRpc-failures.md` says.
- `is not assignable to type 'Layer<never, never, Protocol | State` at `make`'s or `handlers`' `calls`, ending in the services `Y`: the rpc server requires what no Layer provides, such as its group's handlers given with `RpcServer.layer(group)` alone, or a binding's authentication; provide it to the calls, or add its Layer to `services`.
- `No overload matches this call` at `make` with `services` a function of `env`, the last overload saying the function `is not assignable to type 'Layer<`: TypeScript reports the Layer form, as if the services provided nothing; read the requirement error that follows as the two entries above say, the services being the function's.
- `Property 'effectActionsRpc' is missing in type 'DurableObjectStub<...>' but required in type 'Stub'` at `layerStubClient` or `client`'s factory: the class serves no calls over its stub; give `make` `calls`, or define the method in a class of your own, delegating to `handlers`.
- `Effect<Context<Protocol>, never, Sockets>` is not assignable, or `Sockets` missing among a Layer's requirements: `layerWebSocket` registers with the instance's `Sockets`; provide `Sockets.layer`, in the memo map the class dispatches through.
- `The RPC receiver does not implement "effectActionsRpc"`, workerd's, as an `RpcClientError`'s cause: the class defines no such method; define it, delegating to `handlers` ([ActionDurableObject-own-class.md](ActionDurableObject-own-class.md)).
- `Serialized RPC arguments or return values are limited to 32MiB`, workerd's, as an `RpcClientError`'s cause, a defect through `client`: the call's request or answer passed Workers RPC's limit; page large answers, or keep large values in storage, R2 or a socket's stream.
- `Could not serialize object of type "<Class>". This type does not support serialization`, workerd's `DataCloneError`, as an `RpcClientError`'s cause, a defect through `client`: a value of the call, success, error or defect, is one structured clone refuses, such as a class instance in a `Schema.Unknown`; declare its schema, whose plain form clones, or die with an `Error`.
- `Your Durable Object class must have an alarm() handler in order to call setAlarm()`, workerd's, from `storage.setAlarm`: the object was made without an `alarm`; give `make` one, define the class's own, or stop setting it, and on celld 0.6.2, which accepts the call and drops the alarm when it is due, an alarm that never runs means the same.
- `RpcClientError` from every call over a stub, Effect's own error: the stub failed, its `reason.cause` the runtime's or the object's message; a stub an exception broke fails every later call with the same one, so call through `client`, whose factory makes a new stub for each call, or give `layerStubClient` a new stub.
- An upgrade that fails with `RpcServer.layerProtocolWebsocket` in an object's routes, Effect's server: a web handler's request cannot be upgraded by it; serve the socket with `layerWebSocket`.
