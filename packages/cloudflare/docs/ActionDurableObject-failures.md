# ActionDurableObject failure modes

Messages the library does not own, workerd's, the compiler's and Effect's, and the fix. Search for a fragment of the message; one the library throws says its own fix. The tasks are in [ActionDurableObject.md](ActionDurableObject.md); a surface's own failures are in the core's `*-failures.md` pages.

- `is not assignable to type 'Allowed<never, never>'` at `make`'s or `handlers`' `routes`, or `Allowed<X, Y>` where the routes provide `X` and `services` provides `Y`: the routes require a service no Layer provides; those in the union other than `State`, `Alarm`, `Tasks`, `Events`, `Idempotency`, `Sockets`, `Waits`, `HttpRouter`, the platform's and `Y` are missing, so add their Layers to `services` or provide them to the routes, and a `Request<"Requires", Z>` is read per request, as the core's `ActionRpc-failures.md` says.
- `is not assignable to type 'Layer<never, never, ` at `make`'s or `handlers`' `calls`, the union `Alarm`, `Events`, `Idempotency`, `Protocol`, `State` and `Tasks`, with the services among them at `make`, sorted by name: the rpc server requires what no Layer provides, such as its group's handlers given with `RpcServer.layer(group)` alone, or a binding's authentication; provide it to the calls, or add its Layer to `services`.
- `is not assignable to type 'Layer<never, never, Alarm | Events | Idempotency | Protocol | State | Tasks>'` at `handlers`' `calls`, the source type naming a service that `services` gives with `Layer.succeed(Tag, value)`: TypeScript infers no services from the two-argument form there; write `Layer.succeed(Tag)(value)`.
- `is not assignable to type 'Layer<never, never, never>'` at `handlers`' `services`, beside an error at its `calls`: TypeScript infers no services once the calls fail; fix the calls' error, as the entries above say.
- `is not assignable to type 'Alarm | Events | Idempotency | State | Tasks'` at `make`'s or `handlers`' `services`, after `is not assignable to type 'Layer<` naming the services: they require a service other than `State`, `Alarm`, `Tasks`, `Event.Events` and `Action.Idempotency`, which nothing before them builds; provide its Layer to them, `Layer.provide`, or merge it in with `Layer.provideMerge`.
- `provides no match for the signature '(env: Env): Layer<` at `make`'s `services`: `make` takes its services as a function of `env`, never a Layer; write `services: () => layer`.
- `Property 'effectActionsRpc' is missing in type 'DurableObjectStub<...>' but required in type 'Stub'` at `layerStubClient` or `client`'s factory: the class serves no calls over its stub; give `make` `calls`, or define the method in a class of your own, delegating to `handlers`.
- `Effect<Context<Protocol>, never, Sockets>` is not assignable, or `Sockets` missing among a Layer's requirements: `layerWebSocket` registers with the dispatcher of the instance's sockets, which `make` and `handlers` provide; serve the routes through one of them.
- `The RPC receiver does not implement the method "effectActionsRpc"`, workerd's, as an `RpcClientError`'s cause: the class defines no such method; define it, delegating to `handlers` ([ActionDurableObject-own-class.md](ActionDurableObject-own-class.md)).
- `Serialized RPC arguments or return values are limited to 32MiB`, workerd's, as an `RpcClientError`'s cause: the call's request or answer passed Workers RPC's limit; page large answers, or keep large values in storage, R2 or a socket's stream.
- `Could not serialize object of type "<Class>". This type does not support serialization`, workerd's `DataCloneError`, as an `RpcClientError`'s cause: a value of the call, success, error or defect, is one structured clone refuses, such as a class instance in a `Schema.Unknown`; declare its schema, whose plain form clones, or die with an `Error`.
- `Your Durable Object class must have an alarm() handler in order to call setAlarm()`, workerd's, from `storage.setAlarm`, which `Alarm.set` calls: the class delegating to `handlers` defines no `alarm`; delegate `handlers`' own, as `make`'s classes do, and on celld 0.6.2, Deno's self-hosted Durable Object runtime, which accepts the call and drops the alarm when it is due, an alarm that never runs means the same.
- `The Workers runtime canceled this request because it detected that your Worker's code had hung and would never generate a response`, workerd's, from every call through a client kept across a Worker's requests, `client` or `RpcClient.make` over `layerStubClient`, or through a handler or runtime holding one: it was first built lazily inside a request that ended without waiting on I/O, succeeding or refused, whose timer would have started the client's own fiber; run each call as its own program, or share it built at module scope under Effect's sync scheduler, as `HttpRouter.toWebHandler`'s gotchas show, a `ManagedRuntime.make` there building only at its first run, as the stub page says ([ActionDurableObject-stub.md](ActionDurableObject-stub.md)).
- `RpcClientError` from every call over a stub, Effect's own error: the stub failed, its `reason.cause` the runtime's or the object's message; a stub an exception broke fails every later call with the same one, so call through `client`, or give `layerStubClient` a function, `() => stub`, either making a new stub for each call.
